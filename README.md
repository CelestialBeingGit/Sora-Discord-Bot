# Sora Discord-бот 

Многофункциональный Discord-бот, созданный на базе библиотеки `discord.py` v2.0+. Включает в себя таймер продуктивности Помодоро, приватную систему личных заметок на базе SQLite, парсеры игровых новостей и книг, а также поиск аниме. В будущем команды будут расширяться.

# Команды

- Таймер Помодоро (`!pomodoro`): Повышайте свою продуктивность с помощью настраиваемого таймера.
- Приватные заметки (`/note`): Удобно создать, просмотреть и удалить личные заметки. Использует базу данных SQLite. Все заметки отправляются скрытыми сообщениями, которые видите только вы.
- Парсеры новостей и книг (`!gamenews`, `!books`): Автоматически собирает свежие статьи об играх и хиты продаж книг с помощью `BeautifulSoup4`.
- Поиск аниме (`!anime`): Находит описание, оценки и статус выхода аниме напрямую через API MyAnimeList.
- Пасхалка с Широ (`!shiro`): Секретная команда, которая выдает случайную GIF-анимацию с Широ из аниме «No Game No Life».
